# requirements-lock.txt
#
# PURPOSE: record verified package versions and compatibility notes for the
# final reported analysis. This is a partial environment record, not a full
# pip-freeze export: the complete Colab/HPC freeze was not captured as one
# portable environment, and some tools are external binaries.
#
# To create a complete environment-specific lock file, run the following in
# the exact environment used for a rerun and archive the resulting file with
# its Python version and platform:
#
#   !pip freeze > requirements-lock.txt
#
# This file deliberately does not fabricate a complete freeze from a different
# platform. Use requirements.txt for installation and the notebook manifests
# for run-specific package and binary provenance.
#
# KNOWN VERSION-SENSITIVE PACKAGES (found during this project's development
# — pin these especially carefully once you have a working Colab run):
#
#   - dimorphite-dl : API changed between versions — older releases expose
#     a `DimorphiteDL` class, current PyPI release (as used in notebook 06)
#     exposes a function-based API (`from dimorphite_dl import protonate_smiles`).
#     A version mismatch here will raise ImportError, not silently misbehave,
#     so it will be loud — but confirm the pin once locked.
#   - meeko : ligand PDBQT preparation (mk_prepare_ligand.py CLI) — has had
#     breaking changes to its internal Python API across versions; this
#     project only depends on the CLI entrypoint (more stable across
#     versions than importing meeko's internal classes directly).
#   - rdkit : FilterCatalog contents (PAINS/BRENK/etc. catalogues) and some
#     descriptor function locations have shifted across releases historically.
#   - crepes==0.9.1 : used for split-conformal prediction.
#   - xgboost / lightgbm : verbosity/parameter names occasionally change
#     between major versions (e.g. deprecated params silently ignored vs.
#     raising) — worth a smoke-test after any version bump.
#   - venn-abers==1.5.4 : probability calibration in notebook 3, using the
#     VennAbers class and its predict_proba output.
#
# Verified external tool versions used for the released docking/visualization
# workflow: AutoDock Vina 1.2.7, GNINA 1.3.3, PDBFixer 1.12.0, and PyMOL
# 3.1.8. These are not all Python packages and are therefore not represented
# as pip requirements here. Treat requirements.txt plus notebook manifests as
# the installation guidance until a platform-specific full freeze is archived.
